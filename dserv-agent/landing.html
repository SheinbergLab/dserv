What it does

        
    
      
    
    
    
  
    

  
    
    
    Good to know
    
    
    
      
    
        
    Re-run to update
    
        
    The same command updates a box: components move to their latest release, and what the box declares (time role, mirrored rig) is kept unless the command says otherwise.
    
      
    
      
    
        
    Changing what a box is
    
        
    A box type is a declaration. Re-running with a different one installs what the new type needs and turns off the services of components it leaves out — listed under “What it does” before you run anything.
    
      
    
      
    
        
    How the command is put together
    
        
    The URL says what the box is (type, add-ons, rig); flags after bash -s -- say what this run does. The URL is quoted because ? and & mean something to the shell — unquoted, zsh stops at “no matches found” and bash backgrounds the command at the &.
    
        
    Every option: curl -sSL __BASE__/setup | bash -s -- --help
    
      
    
      
    
        
    Lab time
    
        
    A grandmaster defines a site’s time; PTP clients follow it at microseconds on NICs that hardware-timestamp; NTP clients (chrony) cover the rest at tens of microseconds on a wired LAN. Exactly one grandmaster per segment.
    
        
    Re-running the clock command updates the tooling and restarts PTP daemons that changed, so clients re-lock: do it between sessions.
    
      
    
      
    
        
    A workgroup’s machines
    
        
    Every box that has reported in, with its versions and clock.
    
        
    
      
    
      
    
        
    Box types
    
        
    
        
    As JSON: /setup/profiles; what one installs: /setup/plan?profile=NAME.
